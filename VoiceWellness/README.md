# Голос · iOS-прототип

Откройте VoiceWellness.xcodeproj, выберите схему VoiceWellness и устройство с iOS 26+. Для запуска на iPhone выберите свою команду в Signing & Capabilities. Разрешение на микрофон запрашивается при начале записи.

- **Сегодня → Начать замер → Начать запись.** Прочитайте текст и завершите запись. Приложение локально оценивает число слогов, темп речи, темп артикуляции и медиану внутренних пауз от 250 мс. В истории сохраняются метрики. Временный аудиофайл удаляется после обработки или отмены.
- **Динамика.** Графики за 7 и 30 дней строятся по замерам с микрофона. Если пауз от 250 мс не было, значение медианы отсутствует.
- **Телефония · демо.** Заглушка через интерфейс TelephonyAudioSource подаёт синтетический моно PCM 8 кГц в общий анализатор. В будущем реализация должна получать из talk-recording изолированный канал абонента и фактическую частоту дискретизации. Демо не подключается к сети и не участвует в графиках.

Подход к слогам опирается на [скрипт Avrova](https://github.com/kascad/Avrova_v2/blob/main/audio_utils/wav_analizer.praat). Swift-реализация использует порог интенсивности, локальные пики с провалом между ними и проверку звонкости через автокорреляцию. Для VAD используется адаптивный энергетический порог. Темп речи считается после обрезки краевой тишины, темп артикуляции дополнительно исключает внутренние паузы от 250 мс. Пороги и качество детекции на русской речи требуют валидации.

### Балл «Усталость»

Экспериментальный индекс отклонений от личной базы по ручным голосовым замерам. Для каждого дня считаем медианы темпа речи, темпа артикуляции, пауз и CPPS. Отсутствие паузы от 0,25 с учитывается как 0 с. Частота вероятного кашля равна числу эпизодов, делённому на длительность проверенных записей в минутах. Сравниваем с медианой последних семи сопоставимых дней, предшествующих выбранному дню. Личная база применяется к компоненту после трёх сопоставимых дней. До этого используем стартовые ориентиры для предварительной оценки: 2,7 слога/с для темпа речи, 3,35 слога/с для темпа артикуляции, 0,55 с для пауз, 14 дБ для CPPS и 0 эпизодов/мин для кашля. Это параметры прототипа. CPPS сопоставляется по аудиовходу, кашель по типу записи. Данные демотелефонии исключаются.

Для каждого показателя нормируем направленное отклонение на шкалу от −1 до 1 и ограничиваем этим диапазоном. Верхняя граница для темпа речи и артикуляции соответствует снижению на 30% от личной медианы (минимальный делитель 0,3 слога/с), для пауз — увеличению на величину базовой паузы или 0,5 с, если база меньше, для CPPS — снижению на 4 дБ, для кашля — росту на 6 эпизодов/мин. Веса в том же порядке: 25, 20, 20, 25 и 10. Взвешенное отклонение d равно сумме произведений нормированных отклонений на их веса, делённой на сумму доступных весов. Личная медиана соответствует 12 баллам. При d < 0 итог равен 12 + 12 × d, при d ≥ 0 — 12 + 88 × d. Балл округляется до целого. Для оценки нужен минимум один доступный голосовой компонент помимо кашля. Индекс не проходил клиническую валидацию.
